# Manhattan Short-Term Sublet — Search Criteria

Source of truth for the daily agent. Edit this file to change what counts as a match;
the Routine re-reads it on every run.

## Location
- **Manhattan only.** No Brooklyn, Queens, Bronx, Staten Island, or New Jersey, even if
  a listing calls itself "NYC" or is a short commute.

## Term length
- Short-term sublet only. **Not** a lease takeover, **not** a long-term stay, **no**
  12-month or even 3-month minimum commitment.
- Ideal: 1 month, up to ~2 months max.
- Most likely / most welcome: a couple of weeks.
- Concrete trip in mind: leave **Oct 4, 2026**, return **Oct 30, 2026** (~26 nights).
- General window of interest: **October, November, December 2026, and January 2027.**
  Any short sublet whose availability falls inside that window is worth surfacing, even
  if it doesn't line up exactly with Oct 4–30.

## Budget
- Up to **$4,000/month** for stays of ~a month or longer.
- Up to roughly **$1,000/week** for short (1–2 week) stays — so ~$2,000 for two weeks.
- Some flexibility is possible if a listing is otherwise a strong fit. Don't silently
  drop a borderline listing over price — flag it as borderline instead of excluding it
  outright, and say why.

## Red flags — gender-restrictive listings
Watch for listings that:
- Explicitly request a female tenant ("women only," "looking for a girl," "F preferred").
- Describe the household/roommates as all-female in a way that reads as a soft
  preference against a male tenant.

Exclude these from the main "matches" list (the user is male). Do **not** just drop
them silently — note them briefly in a short "excluded — gender-restricted" line so the
filter's behavior is visible, but never present them as a recommended match.

## Reference listings — already contacted, do not re-surface
These are listings the user already found and reached out to the owners about. Use them
as a style/quality benchmark for what a good match looks like — do not report them again
even if they resurface in a search:
- https://www.listingsproject.com/listings/central-greenwich-village-apartment-by-washington-square-park
- https://www.listingsproject.com/listings/sunny-east-village-1-bd-loft-with-private-patio-6ada4685-cdb0-4400-8ed3-

Both are Greenwich Village / East Village sublets sourced via ListingsProject. Good
comparable neighborhoods: Greenwich Village, West Village, East Village, Lower East
Side, Chelsea, Union Square, Gramercy, Murray Hill, Upper West Side, Upper East Side —
any part of Manhattan is in scope, these are just quality comparables.

## Reporting rule
If nothing new and genuinely matching turns up on a given day, the report must say
**"No additional finds."** Never include a listing just to have something to show. Every
reported listing must actually meet the criteria above, or be a clearly-labeled
borderline case (e.g. slightly over budget, dates slightly off) — not a filler result.
